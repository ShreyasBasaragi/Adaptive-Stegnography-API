# Adaptive Steganography API

A FastAPI-based steganography service that hides secret text inside images using an **AI-guided adaptive LSB** pipeline. The core engine analyzes image texture and distributes payload bits across regions with different capacities, so textured areas can carry more data than flat areas.

## Overview

This project provides:

* A REST API for embedding secret text into PNG stego images.
* A REST API for extracting hidden text back from stego images.
* An adaptive pipeline driven by a learned heatmap model (`CamouflageNet`) that estimates where data can be hidden more safely.
* Training and evaluation scripts for working with the model and image dataset.

## How it works

The steganography pipeline uses a learned heatmap to decide how many bits to hide per pixel region:

* **Textured regions** hide **3 bits per channel**
* **Medium regions** hide **2 bits per channel**
* **Flat regions** hide **1 bit per channel**

When text is embedded, the system also appends an EOF sentinel so the hidden payload can be recovered reliably during extraction.

## Features

* FastAPI application with interactive API docs
* CORS enabled for frontend integration
* Adaptive payload distribution based on image content
* Automatic capacity checking before embedding
* Support for optional user-uploaded cover images
* Random cover selection when no image is provided
* PNG output to preserve the hidden payload without lossy compression

## API endpoints

### `POST /embed`

Embed secret text into an image and return a PNG stego image.

**Form fields**

* `text` (required): the secret message to hide
* `image` (optional): a PNG/JPG cover image

**Behavior**

* If no image is supplied, the pipeline uses a random default cover image from the local dataset.
* If the text exceeds the image capacity, the API returns a `400` error.

**Example**

```bash
curl -X POST "http://127.0.0.1:8000/embed" \
  -F 'text=Hello hidden world' \
  -F 'image=@cover.png' \
  --output stego.png
```

### `POST /extract`

Recover hidden text from a stego image.

**Form fields**

* `image` (required): the stego PNG generated by `/embed`

**Example**

```bash
curl -X POST "http://127.0.0.1:8000/extract" \
  -F 'image=@stego.png'
```

**Response**

```json
{
  "text": "Hello hidden world"
}
```

### `GET /health`

Simple liveness check.

**Example**

```bash
curl http://127.0.0.1:8000/health
```

**Response**

```json
{
  "status": "ok",
  "version": "1.0.0"
}
```

## Data and training workflow

The repository includes scripts for the model and dataset pipeline:

* `download_data.py` — download the dataset
* `get_data.py` — prepare the local training data
* `train_adversarial.py` — adversarial training for the steganography model
* `evaluate_quality.py` — evaluate output quality
* `inspect_model.py` — inspect the model

The training code uses a `CamouflageNet` generator and a `Steganalyzer` discriminator during adversarial optimization.
